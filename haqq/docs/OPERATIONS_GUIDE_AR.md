# حقّك — دليل التشغيل: التثبيت والنسخ الاحتياطي والاستعادة وفيديو العرض

هذا الدليل موجّه للشخص المسؤول عن تشغيل منصة حقّك على جهاز أو خادم يعمل بنظام ويندوز مع Docker Desktop.
كل مهمة لها ملف جاهز داخل المجلد `haqq\ops`: اضغط عليه مرتين، أو شغّله من نافذة الأوامر.

## 1. التثبيت لأول مرة

1. ثبّت برنامج **Docker Desktop** من الموقع الرسمي، وثبّت **Git** بالأمر `winget install -e --id Git.Git`.
   شغّل Docker Desktop وانتظر حتى تظهر حالة *running*.
2. نزّل الكود: افتح PowerShell واكتب `cd "$HOME\Downloads"` ثم
   `git clone https://github.com/helfaramawi/paradise-AI-Project.git`.
   ستجد المنصة داخل المجلد `paradise-AI-Project\haqq`.
3. اضغط مرتين على **`haqq\ops\start.bat`**. في أول تشغيل يُنشأ ملف الإعدادات `.env` تلقائياً، ويتم بناء المنصة
   (من 10 إلى 20 دقيقة في المرة الأولى فقط)، ثم يفتح المتصفح على العنوان http://localhost:8090.
4. قبل الاستخدام الفعلي عدّل الملف `haqq\.env`: اجعل `HAQQ_ENVIRONMENT=production`، وضع مفتاحاً سرياً طويلاً
   وعشوائياً في `HAQQ_SECRET_KEY`، وكلمة مرور جديدة لقاعدة البيانات في `HAQQ_DB_PASSWORD`، ثم شغّل `start.bat` مرة أخرى.
   **غيّر كلمة مرور قاعدة البيانات قبل أول تشغيل فقط**، لأنها تُحفظ داخل قاعدة البيانات بعد ذلك.
5. للعروض التقديمية حمّل البيانات التوضيحية الافتراضية بالأمر **`ops\seed-demo.bat`**
   (الحسابات `*@haqq.demo` وكلمة المرور `HaqqDemo!2026`). لا تحمّل بيانات العرض على نظام عميل فعلي.

## 2. الأوامر اليومية

| المهمة | ويندوز | ماك / لينكس |
|---|---|---|
| تشغيل المنصة وفتحها | `ops\start.bat` | `ops/start.sh` |
| إيقاف المنصة (البيانات محفوظة) | `ops\stop.bat` | `ops/stop.sh` |
| نسخة احتياطية مُتحقق منها الآن | `ops\backup.bat` | `ops/backup.sh` |
| نسخة احتياطية يومية تلقائية | `ops\schedule-backup.bat [HH:MM]` | cron مع `ops/backup.sh` |
| استعادة نسخة احتياطية | `ops\restore.bat [اسم النسخة]` | `ops/restore.sh [اسم النسخة]` |
| التحديث لآخر إصدار | `ops\update.bat` | `ops/update.sh` |
| تحميل أو إعادة ضبط بيانات العرض | `ops\seed-demo.bat [reset]` | `ops/seed-demo.sh [reset]` |

## 3. النسخ الاحتياطي

### محتويات النسخة الاحتياطية
كل نسخة عبارة عن مجلد باسم `haqq\backups\haqq_YYYYMMDD_HHMMSS` يحتوي على:

| الملف | المحتوى |
|---|---|
| `database.dump` | كل البيانات: الشركات والمستخدمون والمشروعات والبنود والأحداث والمستحقات والتقييمات والمطالبات والمواعيد وسجل التدقيق |
| `documents.tar.gz` | كل المستندات المرفوعة وكل ملفات المطالبات المُنشأة |
| `env.backup` | ملف الإعدادات بما فيه كلمات المرور ومفاتيح الربط — **احتفظ بالنسخ في مكان آمن وسري** |
| `manifest.txt` | التاريخ، وإصدار الكود، ونتيجة الفحصين، وعدد السجلات في كل جدول، والبصمة الرقمية SHA-256 لكل ملف |

### كيف تثبت النسخة أنها صالحة للاستعادة
لا تُعتبر النسخة مكتملة إلا بعد **نجاح فحصين**:
1. **قاعدة البيانات:** تُستعاد النسخة فعلياً في قاعدة بيانات مؤقتة، ويُقارن عدد السجلات في كل جدول بالقاعدة الأصلية.
2. **المستندات:** يُطابق كل ملف داخل الأرشيف مع البصمة الرقمية المسجلة في قاعدة البيانات لحظة رفعه أو إنشائه.
   أي ملف ناقص أو معدّل يُفشل النسخة.

النسخة التي تفشل في أي فحص يتغير اسمها إلى `failed_haqq_…` حتى لا يُعتمد عليها بالخطأ.

### نسخ احتياطي يومي تلقائي
شغّل **`ops\schedule-backup.bat`** مرة واحدة (الافتراضي الساعة 23:30، أو مثلاً `schedule-backup.bat 02:00`).
بعدها يقوم جدول مهام ويندوز بعمل نسخة مُتحقق منها يومياً، وتجد النتيجة في `haqq\backups\last-scheduled.log`.
يجب أن يكون الجهاز يعمل وDocker Desktop قيد التشغيل في هذا الوقت. للإلغاء: `schedule-backup.bat remove`.

### نسخة إضافية خارج الجهاز (موصى به بشدة)
أضف إلى الملف `haqq\.env`:
```
HAQQ_BACKUP_COPY_TO=E:\HAQQ-Backups
HAQQ_BACKUP_KEEP=30
```
عندها تُنسخ كل نسخة احتياطية تلقائياً إلى هذا المجلد (قرص خارجي أو جهاز تخزين شبكي أو مجلد سحابي متزامن)،
ويُحتفظ بآخر 30 نسخة على الجهاز. السياسة الموصى بها: نسخة يومية تلقائية، والاحتفاظ بثلاثين يوماً، ونسخة خارج الجهاز،
و**اختبار استعادة كل ربع سنة** (البند 4.3).

## 4. الاستعادة

### 4.1 الاستعادة على نفس الجهاز
شغّل **`ops\restore.bat`**. يعرض لك النسخ المتاحة ويسألك عن النسخة المطلوبة، ثم يعرض بياناتها ويطلب منك كتابة `YES`. بعد ذلك:
1. يأخذ **نسخة أمان** من البيانات الحالية (حتى يمكن التراجع عن الاستعادة نفسها)؛
2. يوقف المنصة، ويستعيد قاعدة البيانات وكل المستندات؛
3. يشغّل المنصة، ويعيد **فحص كل ملف مقابل بصمته الرقمية**، ويعرض أعداد السجلات.

### 4.2 الاستعادة على جهاز جديد (التعافي من الكوارث)
1. ثبّت Docker Desktop وGit ونزّل الكود (البند 1، الخطوتان 1 و2). **لا** تُنشئ ملف `.env` بنفسك.
2. انسخ مجلد النسخة الاحتياطية (مثلاً من القرص الخارجي) إلى `paradise-AI-Project\haqq\backups\`.
3. ضع الإعدادات المحفوظة قبل أول تشغيل حتى تُنشأ قاعدة البيانات بنفس كلمة المرور، من داخل المجلد `haqq`:
   `copy backups\haqq_YYYYMMDD_HHMMSS\env.backup .env`
4. شغّل `ops\start.bat` مرة واحدة، ثم `ops\restore.bat haqq_YYYYMMDD_HHMMSS`.
   (إذا كان هناك ملف `.env` مختلف، يحتفظ به البرنامج ويحفظ الملف المستعاد باسم `.env.from-backup`؛ انسخ منه كلمات المرور إذا فشل الدخول.)
5. سجّل الدخول وراجع بعض المشروعات. الاستعادة تكون قد تحققت بالفعل من بصمة كل مستند.

الوقت المتوقع: الاستعادة نفسها تستغرق دقائق، وخطّط لساعة كاملة شاملة التثبيت على جهاز جديد.

### 4.3 اختبار الاستعادة كل ربع سنة
على جهاز احتياطي، اتبع البند 4.2 بآخر نسخة، وتأكد أنك تستطيع الدخول وفتح ملف مطالبة مُنشأ. سجّل التاريخ والنتيجة.
النسخة التي لم تُختبر استعادتها مجرد أمل، وليست نسخة احتياطية.

### 4.4 إذا حدثت مشكلة بعد التحديث
`update.bat` يأخذ دائماً نسخة مُتحقق منها قبل التحديث. إذا لم يعمل الإصدار الجديد بشكل سليم:
`git checkout <إصدار الكود المذكور في manifest.txt>` ثم `start.bat` ثم `restore.bat` بتلك النسخة.

## 5. فيديو العرض العربي مع التعليق الصوتي

1. شغّل المنصة (`ops\start.bat`). ثبّت Node.js وFFmpeg مرة واحدة:
   `winget install -e --id OpenJS.NodeJS.LTS` و`winget install -e --id Gyan.FFmpeg`
   (أغلق النافذة وافتح نافذة جديدة بعدها). وللتعليق الصوتي تحتاج Python: `winget install -e --id Python.Python.3.12`.
2. شغّل **`ops\record-demo.bat`**. يعيد ضبط بيانات العرض، ويفتح متصفحاً مخفياً، ويسجّل جولة عربية من عشرة فصول
   من المنصة الحقيقية (حوالي 10 دقائق بالوقت الفعلي). الناتج: `haqq\docs\video\haqq-demo-ar.mp4` و`haqq-demo-ar.srt` (نص التعليق).
3. شغّل **`ops\make-voiceover.bat`** (صوت رجالي مصري) أو **`make-voiceover.bat female`** (صوت نسائي مصري).
   يحتاج اتصالاً بالإنترنت (أصوات مايكروسوفت العصبية عبر خدمة القراءة المجانية في متصفح Edge). ينطق كل جملة بسرعتها الطبيعية،
   ويثبّت الصورة إذا احتاجت الجملة وقتاً أطول، ويضيف الموسيقى الهادئة بصوت منخفض تحت التعليق، وينتج
   `haqq\docs\video\haqq-demo-ar-voice.mp4`.
   خيارات: `set HQ_MUSIC=none` (بدون موسيقى)، `set HQ_MUSIC_VOLUME=-20` (موسيقى أعلى)، `set HQ_VOICE_RATE=5` (كلام أسرع 5%).

أعد التسجيل كلما تغيرت الشاشات، وسجّل في نفس يوم إعادة الضبط حتى تطابق عبارة "سبعة أيام على موعد الإخطار" التعليق الصوتي.

## 6. حل المشكلات

| المشكلة | الحل |
|---|---|
| رسالة "Docker is not running" | شغّل Docker Desktop وانتظر حالة *running*. |
| فشل `start.bat` أثناء البناء | تأكد من الاتصال بالإنترنت؛ إذا كان هناك بروكسي في الشركة اضبطه من Docker Desktop ← Settings ← Resources ← Proxies، وأرسل رسالة الخطأ لدعم PAIS. |
| مستند يظل "في الانتظار" | `docker compose logs worker`، ثم `stop.bat` و`start.bat`. |
| ملف PDF ممسوح لا يظهر نصه | افتح `http://localhost:8090/api/health/ready` وتأكد من `"ocr": "available"`. |
| فشل النسخ عند خطوة التحقق | لا تحذف النسخ القديمة. راجع `docker compose logs db` وفرّغ مساحة على القرص ثم أعد المحاولة. |
| فشل الدخول بعد الاستعادة | قارن `.env` مع `.env.from-backup` (كلمة مرور قاعدة البيانات والمفتاح السري). |
| لا تصل تنبيهات البريد | اضبط قيم `HAQQ_SMTP_*` في `.env`؛ التنبيهات داخل المنصة تعمل بدونها. |
