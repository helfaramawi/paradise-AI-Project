# HAQQ — Product Roadmap

**Now (MVP, delivered):** contract intelligence (EN/AR, OCR), event register, explainable entitlement discovery,
deadline intelligence, valuation, claims lifecycle & documents, executive dashboard, RBAC/multi-tenancy, subscription
metering, optional Claude narrative/Q&A.

**Next (pilot phase, 0–3 months)**
* Accuracy programme on pilot contracts; reviewer-feedback loop into the taxonomy and gold set.
* Live LLM validation; optional LLM-assisted clause extraction for unusual layouts (always cited, human-verified).
* Neural multilingual embeddings behind the existing interface.
* S3/MinIO storage, antivirus scanning, retention purge job, scheduled deadline scans, httpOnly cookies, SSO (Entra ID).
* Payment-gateway adapter (Paymob/Fawry), invoices with VAT.
* Business-unit UI, bulk upload, document viewer with page highlighting.

**Later (3–12 months)**
* Microsoft 365 / Outlook correspondence capture and classification.
* ERP finance integration (approved vs collected from the ledger; Odoo/Dynamics/SAP — reuse PAIS connectors).
* Primavera P6 / MS Project import for automated time-impact analysis.
* Mobile site-event reporting with photos and voice-to-event.
* Portfolio commercial-risk prediction and claims benchmarking (from consented, human-reviewed outcomes only).
* Industry-specific clause libraries (FIDIC 1999/2017 structures, Egyptian public-procurement law 182/2018 contracts).
